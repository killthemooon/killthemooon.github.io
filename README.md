# Mal — Glass Archive

This folder contains the complete static portfolio website.

## Publish with GitHub Pages

1. Upload every file and the complete `media` folder to the root of the repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.

The public site is read-only. To open the visual editor, add `?edit=1` to the end of the published GitHub Pages URL. After editing, use **EXPORT COMPLETE PACKAGE** to preserve the layout, text, data, images, and video covers together. Browser edits remain on that device until a new website version is uploaded.
